# web

## 1.0.0

### Major Changes

웹 블로그를 첫 안정 버전 1.0.0으로 릴리즈합니다.

### Minor Changes

- 4425e37: 아티클 전용 본문 컴포넌트와 MDX 매핑을 추가한다. 기존 블로그의 본문·안내 상자·제목 링크 스타일을 유지하고, 명조체와 큰 따옴표로 인용을 표현한다. 반응형 이미지 너비와 코드 복사, 빌드 시 Dark+ 구문 강조를 지원한다.
- e0025f1: 홈에 스크롤로 무너지는 그리드 Hero와 작성자 소개, 최근 글·시리즈 큐브를 추가합니다. 키보드·터치 탐색과 모션 감소·Canvas 미지원·JavaScript 없는 환경을 지원합니다.
- 75957dc: Next.js MDX로 포스트 상세 페이지와 공개 글 진입 목록을 연결합니다. 최신 공개 글의 정적 HTML, 날짜와 변경 이유로 선택하는 수정 이력, 과거 본문의 지연 로딩, 버전별 이미지와 목차를 제공하며 모든 발행본의 canonical을 기본 글 주소로 통일합니다.

  사이트는 운영체제 테마와 관계없이 기본 라이트 모드로 표시합니다.

  아티클 표는 옅은 헤더 배경과 행·열 구분선으로 정리하고, 둥근 외곽선이 잘리지 않도록 스크롤 영역에서 테두리를 그립니다.

- b2c8354: 포스트 메타데이터에서 시리즈를 수집해 단일 JSON으로 관리합니다. 시리즈 목록·캐러셀·상세와 포스트의 전체 챕터·현재 위치·이전/다음 탐색을 제공하며, 로컬 초안 미리보기와 공개 집계를 분리합니다. 시리즈 상세의 글 목록에는 기본 캐릭터 썸네일을 표시합니다. URL의 ID와 독립적인 표시 이름을 `label`로 지정할 수 있고, 재수집에도 이름을 보존합니다. 공개 빌드에서 시리즈 제목·소개와 대표 이미지 참조를 검증합니다.

  캐러셀에도 목록·헤더와 같은 최대 너비와 중앙 정렬을 적용합니다.

  캐러셀 전환 시 이전·다음 슬라이드를 전체 너비만큼 좌우로 이어서 이동합니다. 빠른 방향 전환과 동작 줄이기를 지원하고, 퇴장 중인 슬라이드의 포커스·클릭을 차단하며 캐릭터 표정을 유지합니다.

  캐러셀의 현재 위치 막대도 슬라이드와 같은 속도로 부드럽게 이동하고, 동작 줄이기 설정에서는 즉시 갱신합니다.

- 2757a60: 일기 목록·상세·작성·미리보기·발행을 추가합니다. 포스트와 목록·본문 컴포넌트를 공유하며, 일기는 연도 폴더 안에서 기록별 단일 MDX를 직접 수정합니다. 일기에는 고운바탕과 기본 14px 본문을 적용합니다. 시리즈나 버전 이력을 만들지 않으며 초안은 공개 빌드와 사이트맵에서 제외합니다.
