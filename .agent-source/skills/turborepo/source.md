# Turborepo 작업 계약

## 목적

사용 중인 Turborepo 버전의 문서를 근거로 요청한 구성이나 문제를 해결하고, 기존 패키지 경계와 실행 방식을 유지한다.

## 트리거

Turborepo 설정, 작업 의존성, 캐시·Remote Cache, CLI·필터, 환경변수, 워크스페이스 구성 또는 관련 CI를 다룰 때 사용한다. 설명·검토 요청은 파일 변경 없이 처리한다.

## 입력

요청 범위, 저장소의 패키지 관리자와 버전 제약, 설치된 Turborepo 버전, 관련 설정·스크립트·lockfile, 실패 로그 및 해당 버전의 문서.

## 절차

저장소의 실제 구성과 요청을 먼저 확인한다. 설치 패키지에 동봉된 문서의 작업 색인에서 필요한 문서만 골라 읽은 뒤 변경한다. 설치된 버전과 최신 문서를 혼동하지 않고, 요청 범위의 최소 변경과 영향받는 작업 검증으로 마무리한다.

## 검증

구성 검토와 실제 작업 실행을 구분한다. 변경한 작업의 선택·의존성·산출물을 확인하고, 캐시 관련 변경은 해당 입력 변화가 결과에 반영되는지 확인한다. 실행하지 않은 빌드·캐시·CI·배포를 통과로 보고하지 않는다.

## 출력

판단 근거로 사용한 버전과 문서, 변경 내용 또는 진단 결과, 실제 실행한 검사와 남은 확인 사항을 보고한다.

## 제약

프레임워크별 동작은 해당 프레임워크 문서로 확인한다. 사용자가 선택한 패키지 관리자·언어·배포 방식을 유지하고, 이미 허용된 작업 범위를 넘겨 의존성을 설치·업그레이드하지 않는다. 문서를 읽기 위해 패키지를 임의로 설치하지 않는다.

## 중단 조건

필요한 버전·문서 근거가 없거나 권한이 거절되면 그 근거가 필요한 변경·실행을 멈추고 이유를 보고한다. 가능한 읽기 전용 진단은 계속하되, 추측한 설정이나 조건 변화 없는 재시도로 해결하지 않는다.

## Non-goals

이 스킬은 Turborepo 매뉴얼이나 프레임워크 구현 지침을 대체하지 않는다. Remote Cache 로그인·계정 연결, 외부 CI 실행·게시·배포는 설정 검토에 자동으로 포함되지 않는다.
