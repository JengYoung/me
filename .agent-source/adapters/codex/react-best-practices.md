## Codex 실행 방식

1. 루트 `AGENTS.md`가 React·Next.js 작성·수정·리뷰 전에 이 문서를 읽도록 연결한다. `.codex/react-best-practices.md`라는 파일명 자체의 자동 로딩에 의존하지 않는다.
2. 셸 도구로 대상 코드·패키지·프레임워크 설정을 확인하고 이번 변경에 해당하는 규칙을 적용한다. 원문 예시가 필요할 때는 위 기준 커밋의 해당 규칙을 읽고 현재 프로젝트의 공개 API와 실행 환경에 맞춘다.
3. 필요한 검사를 현재 환경의 명령 규칙에 따라 실행한다. 생성·정적 검사, CLI 발견, 실제 동작과 성능 측정 결과를 구분해 보고한다. 쓰기·실행 권한은 현재 세션의 절차를 따르며 이 문서가 권한을 부여하지 않는다.
