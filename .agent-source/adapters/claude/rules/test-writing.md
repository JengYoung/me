## Claude Code 실행 방식

1. 이 문서는 `.claude/rules/test-writing.md`의 `paths`에 맞는 테스트·fixture·설정 작업에서 로딩하는 규칙이다. 루트 `CLAUDE.md`에서도 테스트 작성·수정·리뷰 전에 읽도록 연결하므로 새 파일을 만들기 전에도 적용한다.
2. 실행이 재개된 세션에서는 먼저 Vitest의 함수·Hook·컴포넌트 검증과 Playwright E2E의 앱 단위 통합 검증을 구분한다. `Read`·검색으로 테스트·helper·패키지 스크립트와 정리 설정을 확인하고 해당 범위의 계약을 적용한다. 기존 사용자 변경과 Iris 코어의 예외를 보존한다.
3. `Edit`·`Write`로 작성한 테스트를 공통 계약과 예시에 대조하고 `Bash`로 영향받은 검사를 실행한다. 셸 명령과 도구 권한은 현재 세션의 실행 규칙을 따른다. 이 지침은 실행 권한을 부여하거나 보류를 해제하지 않는다.
4. 실행 범위·결과·예외·미검증 항목을 보고한다. 생성·정적 검사 결과와 Claude의 실제 규칙 로딩·모델 실행을 구분한다.
