## Claude Code 실행 방식

1. 이 문서는 앱·패키지의 JS/TS와 관련 설정 경로에서 로딩하는 규칙이다. 실제 적용은 위 React·Next.js 작업 범위로 한정한다. 루트 `CLAUDE.md`에서도 작업 전에 읽도록 연결해 새 파일 작성에도 적용한다.
2. 실행이 재개된 세션에서는 `Read`·검색으로 코드·패키지·프레임워크 설정을 확인하고 관련 규칙을 적용한다. 원문 예시가 필요하면 위 기준 커밋의 해당 규칙을 읽는다. 기존 사용자 변경과 프로젝트의 공개 API·디자인 토큰·Iris 예외를 보존한다.
3. `Edit`·`Write` 뒤 필요한 검사를 `Bash`로 실행한다. 현재 환경의 명령·권한 규칙을 따르며 보류된 CLI 실행을 재개하지 않는다. 생성·정적 검사와 실제 규칙 로딩·모델 준수·제품 성능 검증을 구분해 보고한다.
