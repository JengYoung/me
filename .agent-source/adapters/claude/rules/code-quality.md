## Claude Code 실행 방식

- 이 문서는 `.claude/rules/code-quality.md`의 `paths`에 맞는 코드·설정 작업에서 로딩하는 규칙이다. 루트 `CLAUDE.md`에서도 해당 작업 전에 확인하도록 연결한다.
- 실행이 재개된 세션에서는 `Read`로 대상 패키지의 스크립트와 품질 설정을 확인하고, `Bash`로 필요한 검사 명령을 실행한다. 수정은 현재 세션의 `Edit`·`Write`·`Bash` 권한을 따른다.
- 자동 수정 전후 변경을 비교하여 사용자 변경과 Iris 코어를 보존한다. 권한 거절을 다른 도구나 전역 설정 변경으로 우회하지 않는다.
- 최종 응답에는 검사한 범위와 실패·미검증 항목을 구분한다. 실행 보류 중 생성·정적 검사 결과를 Claude의 실제 실행 성공으로 보고하지 않는다.
