# 홈 화면과 그리드 모션

## 화면과 콘텐츠

- `/`는 `Break / the Brake` Hero → 작성자 소개·캐릭터 → 최근 포스트 최대 3개 → 최근 시리즈 최대 3개 순서다. 글·시리즈는 각각 기존 상세 주소와 목록으로 연결한다.
- 포스트는 최초 발행일 내림차순, 시리즈는 기존 글을 포함한 최근 수정일 내림차순으로 고른다. 동률은 ID 오름차순이다. 시리즈 표시명은 기존 `label → title → id` 계약을 따른다.
- 기존 빌드 카탈로그만 사용한다. 공개 빌드에는 공개 콘텐츠만, 로컬 미리보기에는 실제 초안도 표시한다. 날짜 없는 초안에 가짜 날짜를 만들지 않으며 같은 날짜 없는 항목은 ID로 정렬한다. 빈 영역에는 준비 중 안내를 제공한다.
- 대표 이미지가 없는 항목은 기존 캐릭터 자산으로 대체한다. 링크를 포함한 최신 콘텐츠는 초기 HTML에 들어간다.
- 홈 시리즈는 데스크톱·모바일 모두 캐러셀로 탐색하며 기본 5초 간격으로 자동 재생한다. 마지막 시리즈 다음에는 첫 시리즈로 순환한다. 기존 시리즈 화면의 Carousel·방향별 전환·연속 입력·터치 스와이프 처리를 공유하며 새로운 캐러셀 라이브러리를 추가하지 않는다.
- 최근 포스트와 시리즈의 섹션 상단은 데스크톱·모바일 모두 `보라색 서브타이틀 → 수평 구분선 → 목록 보러가기 링크` 순으로 한 줄에 배치한다. 구분선이 남는 너비를 채우고 링크는 Body 3(14px)·작은 화살표로 표시하며 터치 영역과 키보드 포커스는 유지한다. 큰 제목 아래나 옆에 별도 목록 버튼을 중복 배치하지 않는다. 링크의 hover·키보드 포커스 시 화살표만 오른쪽 위로 각각 4px 이동해 색상 이외의 피드백을 제공한다. 모션 감소 설정에서는 전환 애니메이션 없이 위치를 바꾼다.
- 홈 시리즈의 소개 문구는 데스크톱·모바일 모두 `이런 것들에 관심 가지며 / 개발하고 있어요` 2줄로 표시한다. 데스크톱은 왼쪽에 서브타이틀·목록 링크·소개·제목 롤링을 두고 오른쪽에 선택한 시리즈를 크게 소개한다. 모바일은 서브타이틀·목록 링크·소개 → 시리즈 소개 → 제목 롤링 순이다.
- 캐러셀 본문은 데스크톱·모바일 모두 큰 시리즈 썸네일 → 큰 제목 → 설명 → 글 수로 구성한다. 시리즈 대표 이미지가 없으면 기존 캐릭터 대체 이미지를 사용하고 썸네일·제목은 해당 시리즈 상세로 연결한다. 본문에서 큐브·개별 최근 글 목록을 중복 표시하지 않는다. 동일한 이미지·콘텐츠를 CSS로 재배치하고, 화면 폭을 감지한 뒤 PC 화면을 모바일 화면으로 교체하지 않는다.
- 제목 롤링은 고정 높이 안에 이전 제목 0.25개 + 활성 제목 1개 + 다음 제목 0.25개만 보이게 한다. 위·아래 일부 노출 영역에는 블러·페이드를 적용하고 활성 제목은 선명하게 중앙에 둔다. 첫 제목 위와 마지막 제목 아래는 빈 공간이며 제목을 복제하지 않는다. 시리즈 수가 늘어도 롤링 영역 높이는 늘리지 않는다. 롤링 안의 글 수는 활성 제목 옆에만 작게 표시한다.
- 이전·다음 버튼, 인접 제목 선택, 가로 스와이프와 번호 버튼은 같은 선택 상태를 갱신한다. 단순 `N/N` 문구 대신 각 시리즈를 직접 선택하는 `01`, `02` 형태의 번호 버튼과 활성 표시를 제공한다. 본문·썸네일의 좌우 슬라이드와 제목의 위·아래 롤링이 함께 움직이며 모션 감소 설정에서는 즉시 전환한다. 스와이프 후 링크 이동을 방지하고 세로 페이지 스크롤은 보존한다.
- 제목 롤링 아래에는 재생 진행 바와 일시정지·재생 버튼을 제공한다. 진행 바는 현재 시리즈의 다음 자동 전환까지 걸리는 시간을 표시하며 일시정지 중에는 멈춘다. 재생을 재개하면 현재 시리즈에 5초를 다시 부여하고 진행 바도 처음부터 시작한다. 전환 타이머는 공유 Carousel에서만 관리하고 진행 바 때문에 매 프레임 React 상태를 갱신하지 않는다.
- 화살표·제목·번호·스와이프로 직접 탐색하거나 키보드 포커스가 들어오면 자동 재생을 중지하며 재생 버튼으로 다시 시작할 수 있다. 마우스가 캐러셀 위에 있는 동안과 숨긴 탭에서는 일시적으로 멈춘다. 모션 감소 설정과 시리즈가 하나뿐인 경우에는 자동 재생하지 않는다. 자동 재생 중에는 슬라이드 변경을 반복해서 음성 안내하지 않는다.
- 이전·다음 화살표는 제목 롤링 영역의 위·아래 중앙에 배치한다. 큰 원형 테두리 없이 작은 아이콘으로 표시하고 터치 영역과 키보드 포커스 표시는 유지한다.
- 홈 시리즈 섹션은 메인 페이지의 기존 래퍼 너비·바깥 여백을 그대로 유지하고, 그 안에서 소개·선택 영역과 시리즈 소개 영역을 1:1로 나눈다. 기본 캐릭터 썸네일은 레퍼런스와 같은 Brand Primary 100 배경을 사용하며 임의의 회색 배경으로 바꾸지 않는다.
- 홈 시리즈에는 개별 최근 글 목록을 전달하지 않는다. 시리즈 소개는 원본 `description`만 사용하고 개별 글의 요약으로 대신 채우지 않는다. 미리보기에서 빈 소개는 준비 중 안내를 표시한다. 시리즈 앞의 독립적인 최근 포스트 섹션은 유지한다.
- 시리즈 선택은 키보드·터치로 사용할 수 있고 선택 상태와 변경 결과를 알린다. 퇴장 애니메이션 중에도 비활성 시리즈의 링크는 포커스와 접근성 트리에서 제외한다. JavaScript가 없으면 정적인 시리즈 제목·소개·글 수·상세 링크를 제공한다.

## 시작·진행·복귀

- 홈 입장은 스크롤 최상단에서 시작한다. CSS 격자와 제목을 먼저 표시하고 Canvas 모듈은 첫 페인트 이후 불러온다.
- 실제 문서의 첫 하향 스크롤 또는 ‘소개 보기’ 버튼으로 한 번 시작한다. 메뉴·카드 내부 스크롤, 상단 탄성 스크롤은 시작 조건이 아니다.
- 중앙에서 바깥으로 퍼지는 파동이 모든 셀을 채운 뒤, 셀을 입체 블록으로 바꾸어 낙하·회전·쌓임을 표시한다. 낙하 시작과 함께 제목을 중앙 소개 영역으로 이동하고 소개·캐릭터를 드러낸다.
- 스크롤 양으로 재생 시간을 제어하지 않는다. 준비 및 전환 동안 최상단을 유지하고, 블록 정지와 제목 이동이 모두 끝나면 일반 문서 스크롤로 돌아간다. 헤더·메뉴·링크의 입력은 계속 사용할 수 있다.
- 역방향 스크롤은 모션을 되감지 않는다. 홈을 떠나 다시 들어오거나 BFCache로 복귀하면 초기 상태로 시작한다. 진행 중 크기 변경은 새 Canvas 크기에 맞춰 그리며 모션을 중복 시작하지 않는다.
- 공통 배경 구현은 `shared/ui/grid-background`에서 소유한다. 현재 적용 범위는 홈뿐이며, 다른 페이지에 배경이나 스크롤 잠금을 자동 적용하지 않는다. 페이지는 시작 조건과 소개 전환만 소유한다.

## 콘텐츠 큐브와 접근성

- 최근 포스트는 부유하는 입체 큐브로 표시한다. 마우스를 올리거나 링크에 포커스하면 요약 면으로 회전하며, Escape·포커스 이탈로 닫힌다. 터치와 Enter는 해당 상세 페이지로 바로 이동한다. 시리즈는 위의 큰 썸네일과 소개 캐러셀 배치를 따른다.
- 키보드 접근 시 입장 모션을 건너뛰어 링크를 즉시 읽고 조작할 수 있다. 장식 배경은 포인터 입력과 접근성 트리에서 제외한다.
- 모션 감소 설정에서는 파동·낙하·부유·제목 이동을 생략한다. JavaScript가 없거나 Canvas 초기화에 실패해도 소개·최근 콘텐츠·기본 탐색을 읽고 사용할 수 있어야 한다.
- 색상·글자·여백·반경은 Figma Brand의 기존 토큰을 사용한다. 배경 블록의 브랜드 그래픽은 Primary 원시 팔레트를 사용하며, 콘텐츠 면·글자·테두리·포커스는 Light/Dark Semantic 토큰을 따른다. 반응형 경계는 1200px이다.

## 수명·성능·검증

- 셀·파편은 최대 2,400개, 동시에 빛나는 셀은 180개, Canvas 버퍼는 2,000,000픽셀 이내로 제한한다. 물리는 60Hz 고정 간격과 프레임당 제한된 보정 횟수를 사용한다.
- 렌더러당 RAF는 하나만 소유한다. 숨긴 탭·화면 밖에서는 정지하고, 파편이 정지한 뒤 연속 RAF를 종료한다. 이탈 시 타이머·관찰자·이벤트·Canvas 버퍼를 정리한다. 프레임마다 React 상태를 갱신하지 않는다.
- Chromium·Firefox·WebKit의 현재 Playwright 엔진에서 기본 탐색과 폴백을 확인한다. View Transition 미지원 환경은 즉시 제목 배치를 사용한다. 실제 기기·엔진을 실행하지 못한 범위는 미검증으로 남긴다.
- 목표는 초기 HTML의 제목·탐색 제공, 모션 구간 프레임 간격 p95 33.4ms 이하, 정지 후 연속 모션 작업 없음이다. 측정 환경·표본·실제 결과를 구분하며 개발 서버 결과를 배포 성능으로 간주하지 않는다.
- 물리 예산·정지·선정 순서는 Vitest, 실제 홈의 시작·중간·종료·역스크롤·재진입·리사이즈·키보드·폴백은 Playwright로 검증한다. Light/Dark 및 mobile/desktop 시각 결과와 미검증 범위를 남긴다.
